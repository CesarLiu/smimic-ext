# SuperMimic：发展、讨论、派生方向与迁移（调研报告）

调研日期：2026-11-02。范围：原论文（arXiv:2610.28480，CoRL 2026 Oral）、[miao-org/awesome-supermimic](https://github.com/miao-org/awesome-supermimic) 收录的 40 个社区项目（2026-11-01 快照）、中英文媒体与社交讨论、相关方法谱系，以及本仓库自己的复现和诊断记录（`docs/EXPERIMENTS.md`、`docs/GENERALIZATION.md`）。

**来源可信度说明**：论文内容已对照 arXiv v1 PDF（2026-10-20，19 页）逐项核对，章节、图表编号均指原文。社区项目的数字取自 awesome-supermimic 对各上游 README 的摘录（作者自报，基本是单 seed、仅仿真）。∇Mimic、DMO 等少数条目只看到了搜索摘要，文中标为【未核实】。

## 0. 结论速览

1. **SuperMimic 新在哪里。**“学一个可微世界模型，再沿它做 BPTT”并不新：SuperTrack 2021、ControlVAE 2022、SuperDyno 2025 在仿真角色上做过，Dreamer 2020、PWM 2025 在通用 RL 上做过。新的是**规模化的摊销加真机部署**：一个确定性世界模型学的是所有动作共享的身体动力学，数据来自**不可微的**普通刚体仿真器（MuJoCo Warp）。再加上解析奖励/观测头、软存活权重、H=32 加 critic 自举和 sim context ξ，就在 12.9 万条动作上，用 1×H100 3 h 超过了 SONIC 在 128×L40 上训练 7 天的发布检查点：GPU·h 约少 7200×（论文保守写作 >1000×），墙钟时间约少 56×。论文把收益归结为世界模型的三个性质：数据增长 264× 时误差稳定、想象 rollout 比仿真器快 10× 以上、一阶梯度比 PPO-WM 少用约 64× 想象步数。
2. **发展速度异常快。**论文 10 月 20 日上 arXiv，没有官方代码。第二天就有从零复现（本仓库上游 CuboiLeo，10-21 的实验日志）；12 天内 awesome 列表收录了 40 个项目，覆盖复现提速、跨形态、感知地形、灵巧手、机械臂、700 块肌肉的人体模型、四足、轮腿、真机部署和 VLA steering。
3. **讨论集中在五个问题上**：(a) 论文口径能否复现，难动作（翻转、侧滚）和长 clip 漂移是重灾区；(b) 基准只测**训练动作覆盖率**，held-out 泛化证据互相矛盾；(c) 速度竞赛（15–50 min 达到 LAFAN1 0/40 失败），以及“到底是世界模型还是一阶梯度在起作用”（∇Mimic 用可微仿真 20 min 达到 0.82【未核实】）；(d) 训练不稳定：后期检查点退化、崩溃，社区普遍需要 EMA 和归一化；(e) sim2real：世界模型只见过仿真数据，社区真机证据很少。
4. **派生方向**可归成九类（第 5 节）。最有学术价值的三条：**世界模型的数据分配和主动采集**（本仓库已定位到翻转失败的主因是重置采样偏置加世界模型数据份额不足）；**梯度质量与接触不连续**；**世界模型的“自知之明”**，即用它做策略弱点搜索和对抗训练（本仓库 margins 实验的主问题）。
5. **“world model for BPTT”能迁移，但有前提。**可迁移性取决于六个条件：动力学跨任务共享、奖励可微且稠密（或能写成已知函数的解析头）、状态结构化、动力学大体光滑或可平滑、有便宜的数据源、短视野加 critic 够用。按这个清单：
   - **已有社区验证**：灵巧手、机械臂、四足/轮腿、肌骨模型、多形态、感知地形；
   - **高潜力**：物理角色动画、无人机、车辆极限操控与赛车、软体/连续体机器人、外骨骼与康复、形态与控制协同设计、系统辨识；
   - **中等**：带物体的接触丰富操作、可变形物体、自动驾驶的规划层（多智能体交互和多模态是难点）；
   - **不适合**：离散/组合决策、稀疏奖励的长时域任务、强随机的多智能体博弈。

## 1. 原工作：SuperMimic 做了什么

### 1.1 方法要点（§3 与 Appendix A–D）

| 组件 | 做法 | 为什么重要 |
|---|---|---|
| 数据源 | 标准刚体仿真器（MuJoCo Warp）的 transition，存进 replay buffer | 不要求仿真器可微，可以用任何现成的高保真仿真器；动力学和采集策略无关，旧数据一直有效 |
| 世界模型 | 确定性 MLP（3×2048），ŝ' = f(ŝ, a, ξ)；k=8 步自回归损失；以每回合 sim context ξ（摩擦、关节偏置、躯干质心）为条件 | 一个模型摊销所有动作；k 步自回归让模型学会纠正自身累积误差 |
| 解析头 | 奖励头和观测头经可微正运动学（FK）解析计算，不学习 | 奖励和观测没有拟合误差，梯度精确；只有动力学是学出来的 |
| 策略优化 | 冻结世界模型，H=32 步想象，一阶梯度 BPTT；软存活权重 ĉ_t 替代硬终止；H 步之后用 critic V(ŝ_H) 自举 | 一阶梯度的方差比 PPO 的似然比梯度低得多；短视野避免梯度爆炸，critic 弥补短视 |
| 确定性策略 | 去掉自碰撞惩罚和推力扰动；关节限位惩罚从 −10 降到 −2 | 自碰撞惩罚防的是随机策略的 reward hacking；状态突变无法被确定性模型捕捉 |
| 课程 | 基于回报的重置采样：1 s 分桶，50% 均匀 / 40% softmax(−25·G/Gmax) / 10% 记忆 | 把采样集中到难的时间段 |
| 接口（Appendix B） | 每个接口一个目标编码器（动作：K=10 未来帧；速度：命令加观测历史特征），共享解码器，32 维 tanh 潜变量；所有接口共用同一个世界模型 | 下游接口可以用自己的任务奖励（RL）经世界模型训练，不必从跟踪器蒸馏 |

### 1.2 论文报告的主要数字

- **算力（§4.1）**：BONES-SEED 过滤后 129,514 条（264.56 h）。1×H100 3 h 的归一化回报超过 SONIC 发布检查点（0.90，128×L40 × 168 h ≈ 21,000 GPU·h）：墙钟约 56×，GPU·h 约 7200×。论文自己列出了口径差异：SONIC 用了 611 h 数据（是 SuperMimic 的 2.3×）；H100 的峰值吞吐是 L40 的 0.74×（fp32）到 5.5×（tensor core）。论文的论点是这两项加起来也解释不了 1000× 的差距。
- **失败数（Table A.8）**：1×H100 3 h 失败 25 条，2×H100 9.8 h 失败 0 条；SONIC 发布检查点 179 条，v1.1 检查点 239 条。

  | 动作组 | SONIC | 1 GPU × 3 h | 2 GPU × 9.8 h |
  |---|---|---|---|
  | 侧滚（22） | **22** | 2 | 0 |
  | 翻转 360°/180°/90°（44） | **44** | 1 | 0 |
  | fire-in-the-hole 转体（20） | 3 | 3 | 0 |
  | 交叉腿（10） | 9 | 0 | 0 |
  | 躺、休息、站起（99） | 28 | 8 | 0 |
  | 立定跳远（24） | 15 | 0 | 0 |
  | 舞蹈套路（8） | **8** | 0 | 0 |
  | 其余（129,287） | 50 | 11 | 0 |

  评测协议（F.1）：两个策略都用 SuperMimic 的训练终止条件判失败；摩擦 1.0，无随机化、无观测噪声，确定性物理，各用自己的执行器增益。SONIC 自己的失败判据只看根部和末端高度偏差 >0.25 m，没有朝向项。
- **与 PPO 的受控对比**（§4.1，LAFAN1 40 条）：PPO-Sim 与 SuperMimic 共享动作、观测、奖励、终止、域随机化、网络大小和评测，每卡环境数是 SuperMimic 的两倍（8192）。SuperMimic 1×H100 1.2 h 达到 0.82；PPO-Sim 18 h 内达不到，最终 0.60（1 卡）、0.70（4 卡）、0.72（8 卡）。
- **机制消融（§4.2）**：
  - 数据从 1 h 增到 264 h，世界模型 8 步误差保持在 0.007–0.011，到达目标回报的 GPU·h 只缓慢增长（读 Fig. 3b，约从 0.5 到 2 GPU·h）；
  - 2k–16k 并行环境时，世界模型比 MuJoCo Warp 快 10× 以上，64k 时快 62×；
  - 在 LAFAN1 的走/跑/冲刺子集上，比 PPO-WM 的最好配置少用约 64× 想象步数达到其最佳回报。
- **critic 与视野（§4.3）**：
  - 没有 critic 时，H ≤ 16 训练失败；有 critic 时，H=16 就能达到无 critic H=32 的水平，H=32 最快达到 0.82；
  - H 从 64 增到 128，耗时约 3 倍，最终回报反而下降；
  - 仿真中站立 T-pose 时施加 0.5–4 m/s 速度推力：有 critic 的策略 0.5–2.4 s 内恢复，无 critic 的策略在 0.5 m/s 时就站不稳，4 m/s 时摔倒。
- **真机（§4.4）**：一个通用跟踪器、不按动作调参，部署到 Unitree G1，展示 4 个动作：skipping jump、侧滚、90° 翻转、原地 360° 翻转。只有演示，没有成功率统计。
- **下游速度接口（§4.5，Appendix G）**：用速度奖励经世界模型做 RL 训练的编码器，和蒸馏基线比较。672 个阶跃命令中 650 个误差更低，中位相对稳态误差 0.16 vs 0.49。蒸馏基线在 7 个快速转向命令（≥2.8 rad/s，动作库里几乎没有数据）上每次都摔倒。单 seed。
- **训练稳定性**：作者称多个 seed 下训练“非常稳定”，归因于跟踪奖励每步都稠密，所以图中不报 seed 方差。这和社区普遍遇到的不稳定形成对比（4.5 节）。
- **论文自述的局限与未来工作（§6）**：
  1. 多接口联合训练研究不足：速度奖励只更新速度编码器，不更新共享解码器，所以“并行训练”等价于先训跟踪器再训编码器；
  2. 世界模型只用仿真数据训练。作者提出可以用真机数据精修，并明确指出**它的可微性可以用于系统辨识**；
  3. 只在平地训练，地形和物体交互是进行中的工作。

  此外 F.2 说明基准测的是训练动作覆盖率，不是泛化。摘要和结论把展望落在：单卡一次运行就能测动作跟踪的 **scaling law**。

### 1.3 方法谱系：它站在谁的肩膀上

| 年份 | 工作 | 关系 |
|---|---|---|
| 2020 | Dreamer v1（Hafner et al.） | 在潜空间世界模型里想象，沿模型把价值的解析梯度反传给策略。思想上的直接祖先，但用的是像素潜模型、小规模任务 |
| 2021 | **SuperTrack**（Fussell, Bergamin, Holden，SIGGRAPH Asia） | 物理角色动作跟踪：学世界模型当可微仿真器的近似，直接优化策略，优于 PPO。SuperMimic 的名字和问题设定都继承于此 |
| 2022 | ControlVAE（Yao et al., TOG） | 联合学习动力学模型、潜技能表示和生成式控制器，下游任务策略经学到的模型训练（论文 Table 1 唯一同样全程 MBRL 的先例，但没有上真机） |
| 2022 | SHAC（Xu et al., ICLR） | 可微仿真里的短视野 actor-critic，截断窗口加 critic 自举。SuperMimic 的目标函数是 SHAC 的变体（软存活、无 EMA 目标网络） |
| 2022–23 | DayDreamer（Wu et al., CoRL） | 世界模型直接在真机上学习 |
| 2022 | Suh et al., *Do Differentiable Simulators Give Better Policy Gradients?* | 指出接触刚度和混沌会让一阶梯度有偏、方差爆炸。这是理解 SuperMimic 为什么用**学到的光滑模型**的理论背景 |
| 2023 | DiffMimic（ICLR） | 用可微物理仿真做动作模仿 |
| 2024 | AHAC（Georgiev et al.） | 接触丰富场景下自适应截断视野 |
| 2024 | MoConVQ（Yao et al., TOG） | 把学到的模型扩展到几十小时数据上的离散动作表示 |
| 2025 | PWM（Georgiev, Hansen, Garg，ICLR） | 在多任务预训练世界模型（TD-MPC2）上做一阶策略提取；论点是正则化的世界模型比真实动力学的优化地形更光滑 |
| 2025 | SuperDyno（Lei et al., *Scalable Humanoid WBC via Differentiable Neural Network Dynamics*，ICLR WS） | 把可微神经动力学扩展到上万条动作片段，最近的仿真人形前驱 |
| 2025 | RWM / RWM-U（Li, Krause, Hutter） | 神经仿真器里训练的策略能上真机，但在想象 rollout 上用 PPO；世界模型在其他策略的数据上预训练（RWM-U 加不确定性惩罚做离线优化）。SuperMimic 则沿模型求导，并在自己采集的数据上边训边拟合 |
| 2025 | Song, Kim, Scaramuzza（CoRL） | 四足：简化的可微代理求梯度，高保真仿真器做前向，是“梯度和前向解耦”的先例 |
| 2025 | BeyondMimic / SONIC | 奖励、终止和观测的来源（BeyondMimic）；PPO 大规模跟踪的对照基线（SONIC） |
| 2026 | **SuperMimic** | 把上面这条线推到人形全量动作库、单卡小时级，并上了真机 |

一句话：SuperMimic 证明了在**动力学共享、奖励光滑可解析**的问题上，“学来的可微代理加一阶梯度”比零阶 PPO 高效三个数量级，而且这个代理可以从任何黑盒仿真器的日志里学出来。论文明确说方法兼容“含非光滑接触、实现不可微”的刚体仿真器（§1）。

### 3.2 跨形态与新本体

- **MorphMimic**：一个策略同时控制 G1 / X2 Ultra / T2，并直接用 PICO 人体追踪做遥操作，不经重定向。真机只测了 G1，后期检查点站立时摇摆。
- 机器人移植：E1（21 DoF）、LimX Oli（31 DoF）、A3、H2、Apple M5（MPS）、RTX 5080（16 GB）。
- **SuperMimic-Quadruped（Rover X1）**：665 条狗动捕 0 失败，加 SONIC 式摇杆规划器，形成“规划器 + 跟踪器”。
- **轮腿（wheelbipe）**：动作库换成速度命令库，6 维动作（4 腿 + 2 轮），归一化回报 0.983。前 800 次迭代混入了 PPO 策略的数据。

### 3.3 感知与地形

- **InstinctMJ**：两条视觉路线。Render 从预测状态里光线投射深度；Latent 预测深度编码器的特征。10 个动作成功率 94.9% / 96.9%。关键发现：**只靠策略梯度训练的编码器比随机编码器还差**，编码器必须用重建等自监督信号训练，策略侧要 stop-gradient。
- Go2 追逃避障（LiDAR/高度图）、G1 跑酷（130 cm 障碍）、高度图自编码器冻结共享。

### 3.4 操作与灵巧手

- **In-Hand Rotation（LEAP Hand）**：世界模型方法 **25 min / 18M 步**达到 PPO 6.5 h / 262M 步的水平；掌心朝下指尖旋转 933°、掉落 4.0%，优于蒸馏后的 PPO 学生（675° / 10.4%）。
- **ARX5 机械臂**：Lemon / BoxInBin / MugHang 在 held-out 重置上 100% / 94.9% / 96.9%。关键技巧是**想象中用可微几何代理代替基于接触的成功判定**。
- Wuji 手魔方重定向和转笔；Sharpa 22 DoF 触觉手（HORA 师生蒸馏，目前只验证了管线）。
- G1 搬箱子：两个 seed 在 31M 步达到 100%。

### 3.5 肌肉、交互、诊断

- **Muscle SuperMimic**：MS-Human-700（700 块肌肉）在 108 条 held-out KIT 动作上 104/108，0.91；MyoFullBody（354 块肌肉）101/108。高维执行器正是一阶梯度相对 PPO 优势最大的地方。
- 后空翻诊断：一帧非足部穿透就让严格验收失败，重跑结果又不同。接触边界对结果非常敏感。
- PERA 滑板：冻结跟踪器，单独训练交互策略。搬箱子和楼梯没成功。

### 3.6 真机与“启发式”实验

- NJU：在 CuboiLeo 基线上针对单段舞蹈微调，22 s 舞蹈在真 G1 上成功 2 次（有安全绳）；另有 ONNX + Unitree SDK2 部署运行时。
- **G0.5 VLA steering**：在冻结的 flow 采样器前训练一个噪声策略，梯度来自世界模型和 critic，任务是 LIBERO。这是**把 BPTT-through-WM 用到生成式策略引导上**的第一个例子。
- **SuperMimic-Decoupled-WBC**（不在 awesome 列表中）：**无参考动作**的速度/姿态命令跟踪，同时抵抗手臂扰动。用 31 项任务奖励在世界模型里训练教师，再沿世界模型用 BPTT 加 DAgger 蒸馏出本体学生。3k 次迭代优于同预算 PPO（113.2 vs 92.8 return）。
- FlatWorld：2D 教学版。

## 4. 讨论焦点与争议

### 4.1 复现性：论文口径能不能做到

- **整体水平能复现**：多个独立实现在 BONES-SEED 全量上达到 0.92–0.94，失败率 0.1–0.3%。
- **难动作复现不了**：CuboiLeo e8 上翻转 54/54 失败，侧滚 19/22。论文 3 h 后只有 1 条和 2 条。
- **本仓库的根因诊断**（`EXPERIMENTS.md` 2026-11-01）是目前对这个差距最具体的解释：
  1. 重置采样的缺陷是主因。clip 结尾不自举，残余尾巴 bin 的 G 很低，40% 的 softmax 份额有 95.5% 落在约 300 个尾巴 bin 上；结果难动作的重置份额只有均匀采样的 0.5 倍。已用 `gmax_mode=remaining` 修复，端到端 A/B 待跑。
  2. 世界模型在难动作上的误差高 7–25 倍（翻转 0.074，侧滚 0.265，对照组 0.010）。只要补这些动作的数据微调，训练 clip 上的误差就降到 0.009–0.018；只用对照组数据训练同样步数（安慰剂），误差反而上升。**瓶颈是数据份额，不是模型容量。**
  3. 航向角在骨盆竖直（|x_z|→1）时奇异，误差随之暴涨。翻转时正好经过这个区域，heading-canonical 表示在这里有缺陷。
- 其他负结果：supermimic_vibe 的论文口径 BONES 训练约 6 h 后崩溃；MorphMimic 和 SuperMimicKit 都报告后期检查点退化。

### 4.2 观测、漂移与评测口径

- 论文的策略观测里没有状态估计。在 100–300 s 的 LAFAN1 整条 clip 上，偏航误差约 9 s 后超过 15°，世界系的根部奖励就拿不到了（0.58 封顶）。BONES-SEED 的 clip 中位数只有 5.8 s，所以看不出这个问题。
- 很多复现加了 BeyondMimic 的锚点相对位姿（+9 维），分数是好看了，但和论文不可比，上真机还需要状态估计。本仓库提供了 `ori` 模式，只用 6 维相对朝向，IMU 可以直接测到。
- 评测分母不一致：除以实际坚持的步数，还是除以整条 clip 的最大值？在失败率高的 LAFAN1 上，这会显著抬高分数。
- awesome 列表反复提醒：**“完成” ≠ “准确跟踪”**；时间是否包含评测；单 seed；只测训练动作。

### 4.3 泛化：证据互相矛盾

| 证据 | held-out 表现 |
|---|---|
| SuperMimicKit G1（LAFAN val37） | **0.31，31/37 失败**（但 23/37 是障碍/被推类动作，平地上本来就不可行） |
| SuperMimic-MuJoCo（100STYLE） | 3,569/3,573 完成，0.80（clip 短，重定向不同，没查语义重复） |
| ScaleBFM_Plus | 2,575 条 held-out 99.5%（Transformer 策略、138k 条数据） |
| Muscle SuperMimic | KIT held-out 104/108 |
| sl221/supermimic-scaling | 1–254 h 数据量与 held-out 泛化的 scaling（本仓库 GENERALIZATION.md 引用） |

可以这样读：**数据量和多样性足够、参考动作物理可行时，泛化不差；类别外的动作和物理上不可行的参考动作会混在一起，拉低 held-out 分数。**本仓库按类别留出的 g 系列实验就是要把这两者分开。

### 4.4 “是世界模型的功劳，还是一阶梯度的功劳？”

- PWM 的论点：正则化后的世界模型比真实接触动力学更光滑，一阶优化反而更好。
- ∇Mimic【未核实】：用有精确接触梯度的可微仿真引擎直接做一阶学习，宣称 20 min 达到 0.82，并发现某个公开复现的附加组件没有带来持久收益（单 seed）。
- 速度竞赛（15 min / 40 min / 50 min）大量依赖工程手段：EMA、小模型、no-sync、归一化。
- **开放问题**：在同一个任务、同等算力下，学出来的世界模型、可微仿真、两者混合（DMO、Coupled Local/Global WM）谁的梯度更好？差距主要出现在哪些状态（接触切换、腾空）？这件事现在没有受控对比。

### 4.5 稳定性与工程

论文说多个 seed 下训练“非常稳定”，图里不报方差（§4）。但几乎所有高分复现都用了下面几样东西，说明论文的超参在其他实现里并不稳健，或者论文有未写出的实现细节：**EMA 策略权重**、**actor/critic/世界模型输入归一化**、**学习率与余弦调度的修正**、**世界模型损失按状态组加权**、**无噪声采集的环境比例**。“训练指标正常、真机却摇摆”（MorphMimic）也说明训练回报不足以判断检查点好坏。

### 4.6 Sim2real

- 论文的世界模型只用仿真数据训练；ξ 只覆盖摩擦、关节偏置和质心三类。论文的真机证据是 4 个动作的演示（§4.4），没有成功率统计。
- 社区的真机证据：NJU 的单段舞蹈微调（有安全绳）、MorphMimic 的 G1（适配了较弱的腰部电机）、部署运行时。**没有人在真机上做过系统评估。**
- 外部评论指出：未建模的柔顺、背隙、热效应和传感器偏置下，世界模型的行为没有被刻画。

### 4.7 算力对比口径

“1000×”、“26×”、“64×” 各有不同的分母：
- 论文的 >1000× 实际约 7200×，对比的是 1×H100 3 h 与 128×L40 7 天。数据量差 2.3×，GPU 峰值吞吐比在 0.74×–5.5× 之间，论文对这两项都有说明（§4.1）；
- 失败数用的是 SuperMimic 自己的终止判据，含倾斜项，而 SONIC 的判据只看高度（F.1）。所以 179 对 25 是在 SuperMimic 的口径下比较的；
- 26× 是社区项目的每步耗时；64× 是想象步数（PPO-WM 对比）。

真正同等条件的对比只有 LAFAN1 上的 PPO-Sim（共享一切设置，1.2 h 达到 0.82 vs 18 h 达不到）。awesome 列表也在每条下提示“这不是同等算力的 time-to-quality 对比”。

## 5. 派生研究方向与开放问题

每个方向给出：问题、现有证据、建议实验。★ 越多越值得做（新颖度 × 可行性 × 影响）。

### D1 世界模型的数据分配与主动采集 ★★★

- **问题**：可微世界模型的误差集中在稀有状态（腾空、倒立、躺姿）。策略的梯度质量取决于模型在**策略要去的地方**准不准，而 replay buffer 的分布由重置采样决定。
- **证据**：本仓库的微调实验（补数据后误差降 5–15×，安慰剂反而升）；InstantTrack 的失败导向重置；allmimic 的均衡采样。
- **建议实验**：
  1. 重置采样同时考虑策略回报和**世界模型误差/不确定性**（集成方差，或 k 步误差的在线估计），对比 `gmax_mode` 的修复；
  2. 世界模型 replay 与策略想象起点用**不同**分布（策略需要课程，模型需要覆盖）；
  3. 世界模型和策略的 scaling law：固定总算力时，模型容量、数据量和 UTD 怎么配。

### D2 梯度质量、接触与不连续 ★★★

- **问题**：一阶梯度在接触切换处有偏差，在混沌区方差爆炸。学出来的模型把这些地方“平滑”掉了，可能有益（PWM），也可能误导（翻转起跳时梯度不给出所需的旋转）。
- **证据**：翻转在角速度冲高时失败，失败前跟踪良好；后空翻严格验收对一帧穿透很敏感；机械臂需要可微几何代理；LocoMuJoCo 的抗饱和正则。
- **建议实验**：在接触事件附近，用有限差分（仿真器）检查世界模型雅可比的方向和幅度；比较梯度的余弦相似度和方差随 H 的变化；试自适应视野（AHAC 思路）、接触感知的状态表示，以及消除航向角奇异的表示（rot6d 或四元数 canonicalization）；与 ∇Mimic 式精确梯度和 DMO 式混合做受控对比。

### D3 世界模型的“自知之明”：鲁棒性、对抗与安全 ★★★

- **问题**：策略只从世界模型的梯度里学，所以同一个模型天然能给出**最坏扰动方向**和**预测的失败幅度**。这个预测准吗？能不能拿来做压力测试和对抗训练？论文训练时去掉了推力扰动，鲁棒性只测了一种情形：站立 T-pose 时施加速度推力（§4.3），结论是 critic 是恢复能力的来源。动作进行中、单脚支撑、落地瞬间等更脆弱时刻的鲁棒性没有被测量。
- **证据**：本仓库的 margins 工具（`--kind adv/state/wm`）就是为此设计的；相关工作有 WorldFailBench、DreamTest。
- **建议实验**：比较 adv 和随机方向的裕度比值、模型裕度的漏报率，以及它们在 heldout_cat 上的退化；然后**用模型的最坏方向在想象中做对抗训练**（可微的鲁棒优化，比随机推力更省样本），再在仿真器里验证裕度。

### D4 部分可观测与状态估计 ★★

- **问题**：长时程跟踪需要全局一致性，但部署只有本体感知。
- **建议实验**：在世界模型里联合学习一个可微的状态估计器（从观测历史估计锚点位姿），让估计误差也沿 BPTT 传播；比较 `none` / `ori` / `pos_ori` 在长 clip 上的漂移曲线；让策略对估计误差鲁棒（在想象中注入估计噪声）。

### D5 Sim2real 与真实数据 ★★

- **问题**：世界模型是可微的，真实数据能不能直接用来修正它？
- **方向**：
  1. 用少量真机 transition 微调世界模型（残差模型，或只调 ξ 嵌入）；
  2. **ξ 的梯度辨识**：模型对 ξ 可微，可以用真实轨迹反推摩擦和质心，把世界模型当可微的系统辨识器（论文 §6 自己提出的方向）；
  3. 真机上的短视野 BPTT 在线适应（类似无人机 RASH-BPTT，把每段 rollout 锚定到真实状态估计）；
  4. 扩大 ξ：执行器延迟、电机强度、背隙。

### D6 超越动作跟踪：任务、交互、感知 ★★

- **问题**：跟踪奖励稠密、光滑、解析，是最适合一阶梯度的问题。到稀疏奖励、物体交互、地形感知上还成立吗？
- **证据**：无参考 WBC（Decoupled-WBC）、搬箱子、跑酷、感知编码器的教训（InstinctMJ：编码器要用自监督训练）。
- **建议**：物体状态进入世界模型（人加物体的联合动力学），成功判定换成可微代理；感知用“预测状态 → 渲染/潜特征”的两条路线（InstinctMJ）；跟踪器冻结、上层任务策略也沿世界模型优化（层级 BPTT）。

### D7 共享动力学的基础模型 ★★

- **问题**：一个世界模型能不能覆盖多种身体（MorphMimic），成为“动力学基础模型”，让新机器人只需少量数据适配？
- **建议**：形态参数化的世界模型（URDF 编码进 ξ），跨本体预训练，再在新本体上少样本微调；评估指标是迁移后的样本效率。

### D7b 多接口联合训练 ★★（论文 §6 第一条局限）

- **问题**：论文里速度奖励只更新速度编码器、不更新共享解码器，所以“联合训练”实际上是先训跟踪器、再训接口。如果让各接口的任务奖励也更新解码器，共享解码器会变好（正迁移），还是会损害动作跟踪（负迁移）？
- **建议**：先在速度、末端位姿、SMPL 身体姿态三个接口上做“更新解码器 / 冻结解码器”的对比，同时看动作跟踪回报和各接口误差；再研究接口采样分布 p(I) 怎么设。

### D8 策略侧：大模型、蒸馏与生成式策略 ★★

- ScaleBFM_Plus 证明了 Transformer 策略可以用 32 步 BPTT 训练；G0.5 证明了可以通过冻结的 flow/diffusion 采样器反传。
- **问题**：BPTT 的梯度能不能直接微调扩散/flow 策略（像 BeyondMimic 那样的引导扩散）？大策略下 BPTT 的显存和稳定性怎么处理（梯度检查点、截断）？

### D9 评测方法学 ★（但社区急需）

- 统一协议：分母、是否计评测时间、多 seed、训练/held-out 分开、物理可行性过滤、去漂移的 MPJPE（本仓库已实现）、扰动下的裕度。
- 一个公开的 held-out 基准（按类别留出加可行性过滤），会比再一个“X 分钟达到 0/40”更有价值。

## 6. 这种 world model for BPTT 能否迁移到其他方向？哪些方向？

### 6.1 先看“为什么在人形跟踪上有效”：可迁移性清单

SuperMimic 的成功依赖下面六个条件。目标领域满足得越多，迁移越容易：

| # | 条件 | 人形跟踪的情况 | 不满足时的后果 / 对策 |
|---|---|---|---|
| C1 | **动力学跨任务共享**：一个模型能摊销大量任务 | 所有动作共享同一个身体 | 每个任务都要单独学模型，摊销优势消失 |
| C2 | **奖励可微、稠密**，最好能写成已知函数的**解析头** | 跟踪奖励是 FK 的光滑函数 | 稀疏或离散奖励没有可用梯度；需要可微代理（几何距离、软成功判定）或回到零阶方法 |
| C3 | **状态结构化、维度适中** | 关节和刚体状态，几百维 | 像素级状态要用潜模型，梯度质量下降（Dreamer 系列的经验） |
| C4 | **动力学大体光滑**，或可以平滑 | 接触有，但多数时间是连续控制 | 强接触切换、碰撞、混沌会让梯度有偏或爆炸；需要短视野、平滑代理、自适应截断 |
| C5 | **有便宜的数据源**：快速仿真器或大量日志 | GPU 并行仿真，每秒 2×10⁵ 步 | 没有仿真器、数据稀缺时，模型误差主导，容易被策略 exploit |
| C6 | **短视野加 critic 足够**：关键因果在几十步内 | 32 步 × 0.02 s = 0.64 s | 长程信用分配（稀疏延迟回报）需要更强的 critic 或层级结构 |

上面的清单可以对应到论文 §4.2 给出的三个收益来源。迁移前应当先在目标领域测这三个量：

1. 数据量增长时，世界模型误差是否稳定（C1）；
2. 想象 rollout 相对原仿真器的加速比（C5）；
3. 一阶梯度相对 PPO-WM 的想象步数节省（C2、C4）。

三者有一项不成立，收益就会大打折扣。

另外两个加分项：**高维连续动作**（一阶梯度相对 PPO 的优势随动作维数增大，见 700 块肌肉、22 DoF 手）；**目标仿真器不可微或很贵**（这时学来的可微代理价值最大，可微仿真路线反而用不上）。

### 6.2 迁移地图

#### A. 已有社区验证（2 周内）

| 方向 | 证据 | 满足的条件 | 备注 |
|---|---|---|---|
| 灵巧手在手操作 | LEAP：25 min vs PPO 6.5 h；Wuji、Sharpa | C1 C2 C3 C5 + 高维动作 | 物体接触是难点；真机还是用的 PPO |
| 机械臂操作 | ARX5 三任务 95–100% | C2（可微几何代理） | 短视野靠重置类别缩短有效时域 |
| 四足 / 轮腿 | Go2 追逃、Rover X1 跟踪 + 摇杆、wheelbipe | C1–C5 | 与人形最接近，几乎是直接迁移 |
| 肌骨人体模型 | 700 / 354 块肌肉，held-out KIT 96% | 高维动作 + C1 C2 | **最有说服力的跨领域证据**之一；PPO 在这种维度上很吃力 |
| 跨形态 | MorphMimic 三种身体 | C1 扩展到形态 | 通向“动力学基础模型” |
| 感知地形 / 跑酷 | InstinctMJ、Go2 地形、G1 跑酷 | 感知用自监督编码器 | 渲染用已知场景网格，真实感知未解决 |
| 生成式策略引导（VLA） | G0.5 在 LIBERO 上 | 冻结生成器 + 可微 WM/critic | 一个实验；思路新颖 |
| 无参考全身控制 | Decoupled-WBC | 任务奖励可微 | 仅仿真、自评 |

#### B. 高潜力、尚少人做

1. **物理角色动画 / 游戏 / 数字人**（★★★）
   - SuperTrack 就出自这里。角色仿真器通常不可微（PhysX、游戏引擎），正好需要从日志学可微代理；动作库巨大（C1）；奖励就是跟踪（C2）；不需要 sim2real。
   - 可做：交互式角色控制器（运动匹配 + 跟踪器），风格化角色，非人形生物，布料和道具的联合模型。

2. **无人机 / 飞行器**（★★★）
   - 动力学光滑（C4 很强）、低维（C3）、奖励可以解析写出。已有可微物理 BPTT 的成功（Back to Newton's Laws 的视觉避障、E2E-Fly、真机上的 RASH-BPTT）。
   - SuperMimic 能补上的：**学来的模型捕捉气动、地效、桨叶下洗**，这些手写可微模型做不到；ξ 可以表示载荷、风和电池电压；“轨迹库跟踪”对应特技飞行轨迹库。

3. **车辆动力学：极限操控 / 赛车 / 漂移**（★★★）
   - 这是与人形跟踪**同构**的问题：一个车辆动力学模型（C1）跟踪大量参考轨迹（赛车线、紧急避让、漂移），奖励是跟踪误差（C2，解析），ξ 是轮胎摩擦、载荷、胎温（对应论文的摩擦和质心随机化），难工况（附着极限附近）正好用基于回报的重置采样集中训练。
   - 高保真车辆仿真器（CarMaker、VI-grade、多体模型）通常不可微，正是“从黑盒仿真器日志学可微代理”的用武之地。
   - 现有相关：Waymax 上的 APG（Nachkov et al., IROS 2025）、Dream to Drive / Analytic World Models（AAAI 2026），都是用**解析可微仿真**；把它们换成**学来的高保真动力学模型**，再扩展到极限工况，是一个清晰的空白。

4. **软体 / 连续体机器人、柔性执行器**（★★）
   - 仿真贵（FEM/MPM），通常不可微或可微但慢；状态可以降维（模态坐标）。学来的可微代理加 BPTT，可以绕开昂贵的仿真器梯度。

5. **外骨骼、假肢、康复辅助**（★★）
   - 直接继承肌骨模型的成果：人体肌骨模型加设备的联合世界模型，优化辅助力矩策略，奖励是代谢代理或跟踪。与 Muscle SuperMimic 天然衔接。

6. **形态-控制协同设计**（★★）
   - 世界模型以 ξ 为条件，而且对 ξ 可微。把设计参数（连杆长度、减速比、质量分布）放进 ξ，就能**同时对策略和设计求梯度**。MorphMimic 的多形态模型是一个起点。

7. **系统辨识与数字孪生校准**（★★）
   - 同一个可微模型反过来用：给定真实轨迹，对 ξ 做梯度下降，就是 D5-2。可用于任何“仿真参数需要对齐现实”的场景。

#### C. 中等：可行，但需要额外机制

| 方向 | 主要障碍 | 需要的改造 |
|---|---|---|
| 带物体的接触丰富操作（装配、插孔、工具使用） | C4：接触切换频繁，成功判定是离散的 | 可微几何代理、物体状态进入模型、更短视野加更强 critic、接触模式感知的模型 |
| 可变形物体（布料、绳索、面团） | C3：状态维度高；C5：仿真慢 | 粒子或图网络世界模型（GNN），降维潜表示 |
| 自动驾驶**规划/决策层** | 其他交通参与者的行为是多模态、随机、交互的；碰撞不连续；有离散决策（让行、变道） | 自车动力学用确定性模型，其他智能体用随机/生成式模型（重参数化后才可微）；碰撞用高斯重叠等软代理（Dream to Drive）；用于**训练反应式策略或生成对抗场景**，而不是直接替代整个规划器 |
| 基于像素的视觉控制 | C3：潜空间梯度质量较差 | 结构化状态 + 视觉编码器（InstinctMJ 的路线）优于端到端像素模型 |
| 过程控制（化工、HVAC、电网） | C5：仿真/数据源；安全约束 | 动力学通常光滑，适合一阶方法；但需要约束处理和不确定性；经典可微 MPC 是强基线 |

#### D. 不适合或收益很小

- **离散 / 组合决策**（棋类、调度、语言生成）：没有连续动作的梯度路径；用 REINFORCE 又回到了零阶方法。
- **稀疏延迟奖励的长时域任务**（开放式探索、长序列装配）：短视野 BPTT 拿不到信号，critic 也很难学；探索是瓶颈，梯度不是。
- **强随机、对抗性的多智能体环境**：确定性世界模型不成立，梯度的期望意义弱。
- **没有仿真器、真实数据也稀缺的领域**：模型误差主导，策略会利用模型漏洞（论文去掉自碰撞惩罚的逻辑也依赖“确定性策略不会 hack”）。
- **需要形式化安全认证的场合**：学来的模型没有保证；可以用作测试工具（D3），不宜用作唯一依据。

### 6.3 非控制类的迁移：把“可微世界模型”当工具

| 用途 | 做法 | 例子 |
|---|---|---|
| 失败搜索 / 压力测试 | 对起始状态或扰动求想象回报的梯度，找最坏方向 | 本仓库 margins 实验；自动驾驶的对抗场景生成 |
| 系统辨识 | 对 ξ 求梯度拟合真实轨迹 | 数字孪生校准 |
| 协同设计 | 对设计参数求梯度 | 机器人形态、执行器选型 |
| 物理感知的动作生成 / 重定向 | 让动作生成器的输出沿世界模型可跟踪（可行性作为可微损失） | 过滤或修复不可行的参考动作（BONES-SEED 的可行性过滤可以学出来） |
| 生成式策略引导 | 冻结扩散/flow 策略，训练噪声或引导网络 | G0.5 |
| 轨迹优化热启动 | 世界模型里的 BPTT 给出初始轨迹，再用真实仿真器或 MPC 精修 | 混合规划 |

### 6.4 迁移配方：保留什么、改什么

**建议保留**（跨领域都有效）：
1. 从黑盒仿真器日志学确定性世界模型，加 k 步自回归损失；
2. 能写成已知函数的部分（奖励、观测、运动学）一律做成**解析头**，只学动力学；
3. 软存活权重加短视野 BPTT，再加 critic 自举；
4. 用 ξ 条件化加域随机化；
5. 失败导向的重置采样，**注意尾部偏置**（本仓库的 `gmax_mode=remaining`）；
6. EMA 策略权重和输入归一化（社区共识）。

**按领域改造**：
- 不连续事件（碰撞、成功判定）→ 可微软代理；
- 多模态或随机的其他主体 → 随机世界模型加重参数化，或者只对自身动力学求梯度；
- 高维观测 → 结构化状态加自监督编码器（不要让策略梯度单独训练编码器）；
- 模型误差 → 不确定性惩罚或集成，并按模型误差主动采集数据（D1）；
- 状态表示的奇异点（如航向角）→ 无奇异的表示。

### 6.5 一个具体的迁移提案：车辆极限操控的 “SuperMimic for vehicles”

（与 6.2-B3 对应，给出可以直接开工的设计。）

- **数据**：高保真车辆仿真器（不要求可微）大规模并行采集；ξ = 路面摩擦、轮胎参数、载荷分布、执行器延迟。
- **任务库**：从真实驾驶日志和赛车线生成数万条参考轨迹（类比动作库），包括紧急避让、低附着路面、漂移。
- **世界模型**：车身 6 DoF 加轮速、胎温等状态，k 步自回归；跟踪误差、横摆稳定性和舒适度写成解析奖励头；“失控”（横摆角或侧偏角超限）作为学习式终止头。
- **策略**：以未来 K 个参考点为目标，H≈32（50 Hz 时 0.64 s，覆盖瞬态操控）BPTT 加 critic。
- **课程**：按回报重置，集中在附着极限附近的工况。
- **评测**：训练轨迹与 held-out 轨迹分开；扰动裕度（D3 的工具可直接复用）；与 MPC 和 PPO 在同等算力下比较 time-to-quality。
- **主要风险**：轮胎在附着极限处高度非线性（C4），需要验证世界模型在这里的雅可比质量（D2 的工具同样可以直接复用）。

## 7. 对本仓库下一步的建议（按优先级）

1. **跑完 `gmax_mode` 的端到端 A/B**（EXPERIMENTS.md 待验证项）。如果难动作通过率显著提升，这是对论文复现差距的第一个因果解释，值得单独成文或提交给 awesome 列表。
2. **margins 主实验**（RUNBOOK 第 1–6 步）：adv 与随机方向的裕度比值，模型裕度的漏报率，train 与 heldout_cat 的对比。这是 D3 方向，目前社区没有人做。
3. **世界模型主动采集**（D1）：重置权重加入世界模型的 8 步误差，看能否不调 `gmax_mode` 也提升难动作，并测试两者能否叠加。
4. **消除航向角奇异**：翻转时 |x_z|→1 误差暴涨，换成无奇异的 canonicalization，检验翻转组误差。
5. **评测口径对齐**：benchmark 同时输出“除以实际步数”和“除以整条 clip”两种归一化，方便与论文和社区对比。
