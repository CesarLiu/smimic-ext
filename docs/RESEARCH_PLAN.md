## 0. 一句话

SuperMimic 为了训练策略，本来就要训练一个可微世界模型。本计划把这个"训练副产品"变成学习型策略的**安全验证工具**，分四步：

1. 用它的梯度去找策略最脆弱的方向。
2. 校准它对失败的预测，得到有覆盖保证的裕度下界。
3. 用 CEGAR 式精化，修正它在反例附近的误差。
4. 用它定位失效点，在仿真中做重要性采样，得到无偏的失效概率估计。

**贯穿全文的原则：世界模型只负责提议，结论一律由仿真给出。** 世界模型的偏差只影响效率（搜索命中率、估计方差），不影响结论的正确性。

| 潜空间安全过滤器（Nakamura 等, RSS 2025）；人形安全过滤器与可恢复性监控（arXiv 2609.15988、2610.33317、2605.19009，2026） | 学习安全集合或过滤器；SPARK 过滤器已有对抗压力测试 | 不与它们竞争过滤器设计本身 |

| WorldFailBench（arXiv 2610.33565）、DreamTest（arXiv 2610.04494） | 世界模型的失败预测与测试 | 需要在动笔前精读，明确区别 |

**本计划的新颖性落在三点：**
1. 世界模型是**策略训练的副产品**，在当前策略的数据分布上学到，复用它不需要额外训练成本。
2. 系统度量并 **conformal 校准**它对失败的预测，给出覆盖保证。
3. 用 **CEGAR 式精化**把它在反例分布上修正，并证明精化不损害训练分布上的精度。

> 动笔前必做：精读 WorldFailBench 与 DreamTest 全文，以及 2026 年人形可恢复性的两篇工作，确认没有重叠。如有重叠，调整 RQ 侧重。

## 4. 方法

### 4.1 记号

- 策略 π，仿真器 f，世界模型 f̂。
- 参考动作的第 t 帧对应名义状态 s_t（取仿真 env 0 的状态）。
- 扰动 δ 定义在归一化误差空间（`StateSpec.error_vector`，70 维）中，默认只扰动速度分量（`component_mask("vel")`）。
- 扰动后的初始状态：`apply_state_delta(s_t, r·d)`，其中 d 为单位方向，r 为尺度。
- **仿真裕度** m_sim(t, d)：使仿真在时域 H 内失败的最小尺度 r，取自尺度网格；不失败记为 ∞。
- **模型裕度** m_wm(t, d)：使世界模型想象展开中存活概率低于 0.5 的最小尺度。

### 4.2 最坏方向（RQ1，已实现）

```
J(δ) = Σ_{k<H} γ^k · surv_k · r_k        （在 f̂ 中想象展开，不用 critic）
d_adv = −∇_δ J / ‖∇_δ J‖                  （限制在速度分量）
```

比较指标（`compare_margins.py` 已输出）：
- `median_log2_adv_over_random`：log2(m_sim(adv) / m_sim(random)) 的中位数，∞ 截断为最大有限值的 2 倍。
- `frac_adv_smaller`、`frac_adv_at_most_half`：最坏方向裕度更小、或不超过随机方向一半的时刻比例。

**增补基线**（RQ1 的论文版本需要）：
- **仿真内黑盒搜索：** 在仿真中直接用交叉熵方法（CEM）搜索最坏方向，预算为每个时刻 K 次分支。这是"不用世界模型"的上限参照。
- **有限差分方向：** 在仿真中用 2·dim 次分支估计梯度。这是"用仿真自己的梯度"的参照，用来回答"世界模型的平滑梯度是否比仿真的数值梯度更有用"。

### 4.3 Conformal 校准（RQ2）

一致性统计 `calibration_stats` 已输出 agree / missed / false_alarm 和 `median_log2_model_over_sim`。在此基础上增加 split conformal：

1. 校准集：随机选取一半的（片段, 时刻）对，计算非一致性分数
   `e_i = log2(m_wm,i) − log2(m_sim,i)`（∞ 截断方式同上）。
2. 取分位数 `q = Quantile_{⌈(n+1)(1−α)⌉/n}(e_1..e_n)`。
3. 测试集上的校准下界：`m_lb = m_wm · 2^{−q}`。
4. **覆盖保证：** 在可交换性假设下，`P(m_sim ≥ m_lb) ≥ 1 − α`。

注意事项：
- 裕度是在尺度网格上取值的，覆盖只在网格分辨率意义上成立。论文中要说明这一点，必要时在关键区间加密网格。
- 可交换性要求校准集与测试集同分布：在 `train_eval` 上校准、在 `heldout_cat` 上测试时，保证不再成立。这本身就是一个结果：需要报告覆盖率掉了多少，并尝试按类别做 Mondrian conformal 校准。
- **用途：** m_lb 可以作为运行时可恢复性监控（机器人 §15 A）：裕度下界低于阈值时，切换到保守策略。

### 4.4 CEGAR 式精化（RQ3）

```
for k = 0, 1, ..., K:
    1. 搜索：在 f̂_k 上对每个时刻计算 d_adv 与 m_wm
    2. 确认：在仿真中分支，得到 m_sim，分类 agree / missed / false_alarm
    3. 收集：把 false_alarm 与 missed 分支在仿真中的状态-动作轨迹
       写入反例缓冲区 B_cex（窗口格式与 ReplayBuffer 相同）
    4. 精化：f̂_{k+1} = 在 B_train ∪ B_cex 上微调 f̂_k
       （WorldModelTrainer.update，按比例 ρ 混合采样）
    5. 守护：在固定的 held-out 训练分布窗口上检查 1 步与 8 步 nse 不变差
```

关键设计：
- **missed 从哪里来：** 世界模型自己找不到 missed，需要仿真侧的搜索来发现（随机方向，以及 4.2 中的 CEM 基线）。所以 B_cex 中的 missed 来自仿真侧搜索，false_alarm 来自世界模型侧搜索。
- **对照组：** 用等量的训练分布新数据微调（不加反例），排除"只是多训练了几步"的解释。
- **指标：** 每一轮的 agree 比例、missed 比例、conformal 分位数 q（越小表示校准越紧）、RQ1 的 `median_log2_adv_over_random`，以及训练分布上的 nse。
- **在策略训练之外进行：** 精化只用于验证，冻结策略。精化后的世界模型是否反过来能改进策略训练，是延伸问题，不在本计划主线内。

### 4.5 重要性采样估计失效概率（RQ4）

**名义扰动分布 p₀：** 需要有物理意义。默认取速度分量上的各向同性高斯 N(0, σ²I)，σ 按 `eval_push.py` 的推力速度换算到归一化空间。也报告多个 σ 的结果。

**失效事件：** F = {扰动后仿真在时域 H 内终止}，目标量 `P_F(t) = E_{δ~p₀}[1_F(δ)]`。

**估计器：**
1. **定位：** 由 4.2 得到 d_adv 与 m_wm，设计点 `δ* = m_wm · d_adv`（世界模型认为最可能失效的点）。
2. **提议分布：** 防御性混合 `q = λ·p₀ + (1−λ)·N(δ*, σ_q²I)`。混合中的 p₀ 部分保证世界模型定位错误时，估计的方差仍有上界（Hesterberg 1995）。
3. **估计：** `P̂_F = (1/N) Σ 1_F(δ_i) · p₀(δ_i) / q(δ_i)`，其中 δ_i ~ q，在仿真中评估 1_F。

**性质：** 只要 q 的支撑覆盖 p₀，P̂_F 就是无偏的，与世界模型是否准确无关。世界模型的质量只影响方差。

**比较（同等仿真预算 N）：**
- 朴素蒙特卡洛（δ ~ p₀）。
- 仿真内的交叉熵重要性采样（CE-IS，不用世界模型，自适应迭代）。
- 本方法（世界模型定位加单轮重要性采样）。
- 本方法 + 精化后的世界模型（RQ3 的产物）。

**指标：** 相对误差 `std(P̂)/P̂`（多次重复）、有效样本数、达到给定相对误差所需的仿真次数。

### 4.6 可选：规约头与过滤器进入 BPTT（RQ5）

- **规约头：** 在想象轨迹上计算 STL 鲁棒度。对象包括关节限位、躯干倾角、足底高度/滑移、自碰撞代理距离，用光滑 min/max（log-sum-exp）近似，作为额外的奖励或约束项。
- **过滤器：** 对少量约束，用闭式解或可微 QP 层实现 CBF 过滤，放进想象展开。
- **比较：**
  - 只在部署时过滤。
  - 训练中加入过滤（参照 CoFiT，arXiv 2610.02341）。
  - 无过滤。
- **指标：** MPJPE、回报、违规时间比例、最小屏障值。

## 7. 决策门

**G1（M1 之后）：世界模型是否知道策略在哪里脆弱？**

| 结果 | 判断 | 下一步 |
|---|---|---|
| adv 裕度不超过随机方向一半的时刻 ≥ 50%，且 missed ≤ 30% | 提议有效 | 按计划进入 M2 到 M4 |
| adv 明显优于随机，但 missed > 30% | 提议有用但不可靠 | RQ3 提前，作为主贡献 |
| adv 不优于随机，但 CEM 或有限差分明显更好 | 世界模型的梯度没有信息 | 检查平滑问题（接触附近），尝试多步梯度或随机平滑；仍不行则把论文重心转向"世界模型何时不可信"的负面结果加 RQ4（RQ4 对世界模型质量不敏感，仍然成立） |
| 所有方向都很难让策略失败 | 扰动空间或尺度网格不合适 | 扩大尺度网格，加入位置或关节扰动，或换用更难的片段 |

（阈值是初始设定，看到 M0 的分布后可以调整，但要在看 M1 结果之前定下来，并在本文档中记录调整。）

**G2（M3 之后）：精化是否有效？**
- 若精化后 agree 比例提升且训练分布 nse 不变差：作为主贡献之一。
- 若改善只与对照组相当：如实报告，论文重心放在 RQ1、RQ2、RQ4。

## 8. 风险与对策

| 风险 | 可能性 | 对策 |
|---|---|---|
| 世界模型的平滑梯度在接触附近指错方向 | 中 | 仿真裁决保证不出错；加入有限差分基线量化差距；必要时用随机平滑梯度 |
| 反例远离训练分布，世界模型完全不准 | 中 | 正是 RQ3 要解决的问题；RQ4 无偏，不受影响 |
| 裕度网格太粗，conformal 覆盖失去意义 | 中 | 在关键尺度区间加密网格，或对 m_sim 做二分细化 |
| 长片段上并行环境的混沌发散 | 已处理 | 每步同步到 env 0（1b13f4b），drift 门槛为 0.01 |
| 新颖性与 WorldFailBench/DreamTest 或 2026 人形工作重叠 | 中 | 第 2 节"动笔前必做"；把贡献落在"训练副产品加校准加精化"的组合上 |
| GPU 时间不够 | 中 | 优先 RQ1、RQ2、RQ4；RQ3 可缩小规模；RQ5 放弃 |
| 许可与身份 | 低 | 保持个人学术研究性质，不使用雇主资源和数据 |

## 9. 预期贡献

1. **度量：** 第一次系统度量一个由策略训练得到的可微世界模型，对策略失败方向和失败裕度的预测能力，包括分布外类别上的表现。
2. **保证：** 用 conformal 方法把模型裕度校准为有覆盖保证的可恢复性下界，可作为运行时监控。
3. **精化：** CEGAR 式的反例回灌，在不损害训练分布精度的前提下修正世界模型在反例附近的误差。
4. **估计：** 世界模型定位加防御性重要性采样，给出无偏、低方差的失效概率估计。世界模型的偏差只影响效率，不影响正确性。

**候选标题：**
- *Does the World Model Know Where the Policy Is Weak? Calibrated Model-Based Falsification for Learned Humanoid Controllers*
- *Propose in the Model, Decide in the Simulator: Verifying Learned Controllers with Their Own World Models*
